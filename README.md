# ☕ Coffee Sales Dashboard | Power BI

An interactive Power BI dashboard designed to analyse coffee shop sales performance and identify patterns across products, time periods and purchasing behaviour.

## 🎯 Project Overview

This project explores coffee shop transaction data to understand sales performance and identify patterns that could support business decision-making.

The dashboard provides an interactive view of key sales metrics and allows users to analyse performance by:

- Product
- Product category
- Date
- Weekday
- Time of day
- Month

## 🛠️ Tools & Technologies

- **Power BI** – dashboard development and data visualisation
- **DAX** – calculated measures and KPIs
- **Power Query** – data cleaning and transformation
- **Kaggle** – source dataset

## 📈 Key KPIs

The dashboard includes key performance indicators such as:

- Total Revenue
- Total Transactions
- Average Transaction Value
- Sales by Product
- Sales by Category
- Sales by Time of Day
- Sales by Weekday
- Monthly Sales Performance

## 🔍 Key Analysis

The dashboard was designed to answer questions such as:

1. How do sales change over time?
2. Which products generate the highest revenue?
3. Which product categories perform best?
4. What time of day generates the most sales?
5. Which weekdays have the highest sales activity?
6. How does purchasing behaviour vary throughout the day?
